# 0.4.7.15

- Held widgets can tilt and turn; roll stays locked. Angle controls offer five-degree adjustments during Edit layout.
- Corner grabs blend into thumb/index pinch poses and follow the corners while resizing.
- Each widget has a touchable pencil in Edit layout. Its local backplate-opacity slider dims surrounding widgets temporarily, leaving their saved values unchanged.
- Feed headings and empty-feed labels appear only while editing. Actual warnings and messages remain visible.
- Crash notifications use a compact recovery feed instead of returning to the old upper-left HUD. Full map, expanded chat and menus retain their native presentation.

Saved layouts remain intact. Exit Edit layout to remove the pencil, slider, labels and corner guides.
