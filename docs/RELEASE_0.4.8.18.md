# 0.4.8.18

- Restores ordinary unit-death and mission/radio text in the movable Notifications widget. Native message timing and kill-feed filters are retained.
- Enlarges kill-feed, mission/radio and instruction text by about 20%, with more room for each row.
- Keeps the original floating feed hidden when the radial wheel, map or menus interrupt cockpit widgets. Native chat still shows its history.
- Throttle/collective thumbstick up/down now supports Ibis pusher fans and Alkyon wing sweep, alongside existing nozzle controls. Turn Flight Assist off on the Ibis to retain a manual fan setting.
- Stabilizes sleeve posing against native head-turn animations and supports the elbow through deep collective bends. Existing glove grips are unchanged.
- Expands the native red damage effect across both eyes using the headset's actual view, retaining the game's artwork, intensity and fade.

Includes the mission-preview and optional head-clearance fixes from 0.4.8.16–17. Existing layouts and controller bindings are retained.
