# 0.4.8.23

- Slightly smaller kill-feed text by default.
- Text size sliders for Notifications and Instructions, available from each
  widget's pencil popup and View → Widget appearance. Changes preview live and
  save with the aircraft's layout slot. Other widgets have no text-size control.
- Starting HUD layouts sit farther forward, with the side groups spread a
  little wider. Both corners stay within reach for resizing; saved layouts are
  unchanged.
