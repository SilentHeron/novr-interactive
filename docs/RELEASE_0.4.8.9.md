# 0.4.8.9

- Eject in the hand wheel now requires a centered stick-click hold for 1.2 seconds. A red eject symbol, expanding progress ring and rising vibration show confirmation progress. Releasing resets the hold; tilting the stick or pressing trigger cancels.
- Helicopters now use the same FS-20 stick model and fitted hand pose as planes. The utility-helicopter collective and saved handle positions are retained.
- The throttle's inboard percentage/state readout is 50% larger, with more spacing and clearance from the slider.

Headset feel still needs testing.
