# 0.4.8.2

- The floating map has fingertip-operated +/− zoom buttons. Touch the map to enable a subtle border and centre crosshair; touch again to resume normal flight bindings.
- While the map is selected and the virtual flight stick is held, the physical right thumbstick pans it. Clicking selects an eligible native target under the crosshair. Return the thumbstick to centre before panning after each grip acquisition.
- Map input takes priority over the right thumbstick's flight bindings and option wheel. Other buttons, stick tilt and twist remain available. Menus, layout editing and tracking loss cancel map selection.
- In Edit layout, grabbing opposite map corners changes width and height independently while retaining movement and tilt. Terrain and icons keep their proportions. Map shape is saved in the current aircraft's profile slot; existing layouts load unchanged.
