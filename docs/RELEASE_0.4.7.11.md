# 0.4.7.11

- Restores missing weapon, countermeasure and power readouts after removal of the replacement MFDs.
- Adds six movable HUD widgets: weapons, countermeasures, power, incoming missiles, electronic warnings and notifications.
- View → HUD layout offers direct grabbing with rotation locked, grip + thumbstick resizing, opacity, optional backgrounds, visibility and edge alignment. Empty widgets show placeholders while editing.
- Save/cancel previews, per-aircraft layouts and a shared default. Seat adjustments, recentering and handedness leave the widgets fixed in the aircraft.
- Pauses flight and physical cockpit interactions while arranging widgets. Native warning displays return when their custom replacement is disabled; native sounds and updates remain active.

Requires in-headset testing of placement and readability. No replacement cockpit displays or extra rendering cameras are added.
