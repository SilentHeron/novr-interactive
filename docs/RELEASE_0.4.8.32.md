# 0.4.8.32 — mouse input hotfix

- Fixed mouse clicks being blocked by idle VR controllers. Fresh controller input switches back to the hand pointer.
- Mouse input remains available when the game window has focus but the headset does not. Switching pointers or menus no longer replays held clicks.
- Added startup loading-screen compatibility with Blueprinter 2.1.1; 2.0.1 remains supported.

One package for Windows and Linux/Proton. Saved layouts and bindings are preserved.
