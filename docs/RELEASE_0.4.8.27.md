# 0.4.8.27 — private test candidate

- Thumbstick click opens a two-option **VR Menu / Game Menu** wheel when dead,
  unspawned, ejected or spectating, including from the spawn map.
- External views use the game's normal camera distance on a stationary screen
  in VR. Right stick orbits; left stick up/down changes distance. In free-camera
  mode, right stick looks and left stick pans.
- Menus take priority over camera controls. Center the sticks after leaving a
  menu; entering an aircraft restores normal cockpit VR.
- Includes the .26 foveation strength slider and Extreme / Maximum test levels.

The spectator presentation needs headset testing. Existing layouts, bindings and
graphics preferences are retained. This remains an unpublished test package.
