# 0.4.8.3

- Widget corners are easier to grab in Edit layout. The second hand gets a larger catch area and priority on the held widget; a first grip near an edge can still become a two-hand resize without jumping.
- Visible hands and opaque sleeves now provide depth for floating cockpit widgets, so panels stop drawing over a closer hand. Native cockpit materials and the headset's eye projections remain unchanged.
- Map hover, selection and zoom presses have stronger, distinct haptic feedback. Successful presses also play the existing interaction sound.
- Deselecting the map immediately recenters it on the aircraft and resumes following it, retaining zoom.
- Removed the detached white map-grid readout from the corner of the VR view. Coordinates and grid labels inside the full map remain available.
