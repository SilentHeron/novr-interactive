# 0.4.8.15

- During Edit layout, clicking either thumbstick reopens the layout menu to save, cancel or continue moving. Quest users no longer need the unavailable radial wheel or physical Menu button.
- Unsaved positions are preserved, including when opening the menu while holding a widget or using a physical HOTAS.
- Layout instructions now show the shortcut. Normal controller bindings are unchanged.

Includes the physical HOTAS layout-editing fix from 0.4.8.14.
